
## 안경원(안경사) 맞춤형 렌즈 B2B 주문서 변환 및 교체 주기 CRM
* 실제 시장의 틈새: 로컬 안경원들은 여전히 오래된 구축 POS 프로그램에 의존합니다. 고객의 시력 검사 데이터(도수, 난시 축 등)를 측정한 뒤, 호야, 자이스 등 각기 다른 렌즈 제조사의 B2B 발주 포털에 들어가 양식에 맞춰 데이터를 매번 새로 수기 입력해야 하는 번거로움이 있습니다.
* 서비스 형태 (APM Web):
    * 시력 데이터를 웹에 한 번만 입력하면, 각 렌즈 제조사별 B2B 발주 양식에 맞는 텍스트나 포맷으로 자동 변환해 줍니다.
    * 여기에 더해 "성장기 어린이 6개월 렌즈 교체 시기" 등을 계산해 고객에게 카카오 알림톡을 보내주는 가벼운 CRM 기능만 붙여도, 무거운 범용 CRM을 쓰기 부담스러운 소상공인 안경사들에게 즉시 가치를 제공합니다.

## 안경원 B2B 발주 양식 자동 변환기
* 렌즈 제조사별 B2B 양식을 AI(저)가 알고 있나?
    * 아니요, 저(AI)나 일반 외부인은 각 제조사(호야, 자이스, 에실로, 케미 등)의 폐쇄적인 사업자 전용 발주 포털 내부의 웹 폼(Web form)이나 엑셀 구조를 실시간으로 열람할 수 없습니다.
* 그렇다면 개발자 관점에서 이 데이터를 어떻게 확보하고 시스템화하는가?
    * 공통된 광학 파라미터 활용: 안경 렌즈 처방의 데이터는 전 세계 표준입니다. SPH(구면도수), CYL(난시도수), AXIS(난시축), ADD(가입도), PD(동공간거리) 등의 고정된 파라미터를 사용합니다.
    * 데이터 양식 수집 (발품/협업): 현직 안경사 커뮤니티나 지인을 통해 각 제조사 B2B 사이트의 '엑셀 일괄 업로드 양식(헤더값)' 샘플을 구하거나, 주문 폼의 HTML 구조를 캡처받아야 합니다. 이 도메인은 매우 특수해서 안경 광학이나 해당 업계에 관심이 있는 분이 아니면 시도조차 하지 않는 영역이라 진입 장벽이자 해자가 됩니다.
    * 자동화 구현 (Python 활용):
        1. 안경사가 개발자님의 서비스 웹 화면에 SPH, CYL 등의 도수와 렌즈 종류를 단 한 번만 입력합니다.
        2. 개발자님의 Python 백엔드가 이를 각 제조사의 엑셀 업로드 양식에 맞게 Column을 자동 매핑하여 엑셀 파일로 뱉어주거나,
        3. 한발 더 나아가, Python(Selenium/Playwright)을 이용해 안경사의 로컬 PC나 서버에서 해당 제조사 B2B 포털에 로그인 세션을 유지한 채 주문 값을 자동 Submit(대리 입력) 해주는 방식을 취할 수 있습니다.
